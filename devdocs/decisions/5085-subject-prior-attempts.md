# 5085: prior attempts are found by subject, not only by file

Recall and the context pack found earlier work only by issue number or touched file, so a fix for the same failure in a different file was never seen. `scripts/prior-attempts.mjs` prints a `## Prior Attempts` table from closed issues and merged PRs matched by subject terms (codes, symbols, title words) through `gh api search/issues` and a repo-wide `git log --grep`; it shares `subjectHistory` with the context pack's `attempts` source (bin/lean/context.mjs). `/issue` runs it for bug/fix drafts, and `investigate.md`/`build/context.md` run it, with a WARNING, when the Forge Ledger index is absent. `scripts/issue-create.sh` warns on stderr when a bug/fix body has no `## Prior Attempts`; it never blocks, and exit codes and `ISSUE_CREATE_RESULT` lines are unchanged.
